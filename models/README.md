# Saved Model Artifacts

This directory stores serialized models and preprocessing transformers generated by `src/train_regression.py` and `src/train_classification.py`.

## Preprocessing Transformers
- `preprocessor_exp_a.joblib`: ColumnTransformer for Experiment A (Early Prediction, excluding G1 and G2).
- `preprocessor_exp_b.joblib`: ColumnTransformer for Experiment B (Mid-Term Prediction, including G1 and G2).

## Regression Models (Target: G3 [0-20])
- `regression_exp_a_*.joblib`: Linear Regression, Decision Tree, Random Forest, Gradient Boosting (Exp A).
- `regression_exp_b_*.joblib`: Linear Regression, Decision Tree, Random Forest, Gradient Boosting (Exp B).

## Classification Models (Target: At-Risk [G3 < 10])
- `classification_exp_a_*.joblib`: Logistic Regression, Random Forest Classifier (Exp A).
- `classification_exp_b_*.joblib`: Logistic Regression, Random Forest Classifier (Exp B).

## Best Performing Models
- **Early Prediction (Exp A)**: Random Forest Regressor (MAE 3.15, R² 0.24) and Logistic Regression (AUC 0.71).
- **Mid-Term Prediction (Exp B)**: Gradient Boosting Regressor (MAE 1.15, R² 0.81) and Logistic Regression (AUC 0.98, Accuracy 91.1%).
